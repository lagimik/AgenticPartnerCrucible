# AI Assistant Skills

AI assistant skills are reusable instruction packages that teach an AI coding assistant how to perform domain-specific work. The preserved `skills-for-fabric` README describes guidance for workload APIs, query patterns, and operational best practices for [[microsoft-fabric]]. It does not independently verify every skill's safety rules or routing triggers.

## Why It Matters

Skills turn implicit expertise into repeatable operating procedures. They let a general assistant behave more like a specialized practitioner without relying only on model memory.
