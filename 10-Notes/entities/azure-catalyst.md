# Azure Catalyst

The November 2026 announcement uses Azure Catalyst for a discovery and assessment
workflow comparing webapp readiness, remediation, sizing, and cost across Azure
targets. Its linked assessment documentation is under Azure Migrate. This source
does not by itself establish a complete product rename or automatic migration.
