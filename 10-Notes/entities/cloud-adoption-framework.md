# Cloud Adoption Framework

The Microsoft Cloud Adoption Framework (CAF) provides adoption and architecture guidance. This page connects the CAF sources reviewed in this vault; it is not a claim that every framework phase or linked implementation has been evaluated.

## AI readiness

The [AI Ready guidance](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ai/ready) starts from existing Azure landing-zone governance, platform capabilities, and workload boundaries. Extend the baseline for approved AI services/models and account for regional capacity, governed data, and recovery dependencies. Separate platform responsibilities from workload delivery and operational ownership.

Reference guidance does not demonstrate that a customer's policy assignments, runtime permissions, network controls, or recovery design are effective.
