# Fabric Apps

Fabric Apps uses the Rayfin TypeScript SDK and CLI to define and deploy
data-driven applications as managed Fabric items. The dedicated November 17
announcement states Rayfin and Fabric Apps GA; nested capabilities and
licensing paths need separate verification.

App access, entity policies, and source authorization are separate.
SQL application identity behavior differs from the announcement's broad
item-identity wording; semantic-model connectors use delegated access.
