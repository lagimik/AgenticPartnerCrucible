# Microsoft Agent 365

Microsoft Agent 365 is Microsoft's agent-management platform, described in the
November announcement as extending enterprise identity, administration, security
and compliance infrastructure to supported agent scenarios.

Agent ownership, purpose, identity type, registry representation, discovery and
runtime protection are related but distinct controls. Platform GA does not
establish that every connector, cloud discovery feature or policy is GA or
enforced for every agent.
