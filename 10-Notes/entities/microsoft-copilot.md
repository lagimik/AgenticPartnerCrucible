# Microsoft Copilot

Microsoft's workplace AI experiences include chat, Cowork, and integration with
Microsoft 365 applications. The November cost-comparison article describes
subscription-included everyday work, metered advanced agent workflows, Work IQ
context, and Auto routing. Actual entitlements, usage charges, permissions,
configuration, and task quality require scenario-specific verification.
