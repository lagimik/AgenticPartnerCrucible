# Microsoft Copilot

The Ignite source uses Microsoft Copilot as a family of work experiences,
agents and execution services. Home, Cowork, Autopilot, Code, Workspaces and
Managed Runtime are distinct surfaces; a single release label or license
does not describe all of them.

Work context, action permissions, identity, runtime, spending and human
approval need separate treatment.
