# Microsoft Edge

Edge for Business is the browser surface in the Ignite source for managed
human/agent browsing, workflow recording, extension safety and enterprise
security integrations. The source assigns different statuses to these
capabilities; browser presence alone does not establish agent-policy enforcement.
