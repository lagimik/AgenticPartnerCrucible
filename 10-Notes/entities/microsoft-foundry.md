# Microsoft Foundry

Microsoft Foundry is the model and agent development platform used by the
sources linked below. Availability varies by capability: the October Decisions
API announcement is GA, while the reviewed fine-tuning additions and shared
Multi-LoRA serving are public preview.

As of the November 2 source review, the Microsoft Copilot harness in Foundry
Agent Service is public preview, while hosted-agent long-running resilience
and Claude resource-level cost allocation are separately announced as GA.
Do not inherit one capability's release status or billing rules for another.
