# Microsoft IQ

The Ignite source describes Microsoft IQ as an enterprise AI platform grouping
context management and continuous improvement on existing Microsoft products.
Its no-new-SKU/GA framing does not remove underlying license, usage, permission
or integration-preview requirements.

## Context Surfaces

| Surface | Source-described emphasis |
| --- | --- |
| Work IQ | Work signals, relationships, retrieval and supported actions |
| Fabric IQ | Business data, semantic models, measures and ontologies |
| Foundry IQ | Unstructured enterprise knowledge, retrieval and grounding |
| Web IQ | External knowledge with source scopes and citations |

These are linked parts of an architecture, not interchangeable databases or
proof of universal cross-platform connectivity. Specific integration and
release-status tensions are preserved in the [Ignite resource](../../40-Resources/ignite-2026/microsoft-iq.md).
