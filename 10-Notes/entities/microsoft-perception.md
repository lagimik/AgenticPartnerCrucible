# Microsoft Perception

Microsoft's multi-agent security system, previously introduced as Project
Perception. The November update describes specialized Defender agents reasoning
over supported third-party telemetry. Triage GA covers selected Microsoft-generated
Okta/Salesforce alerts, not every agent or source. Investigation and detection
authoring depend on connected data and accountable analyst review.
