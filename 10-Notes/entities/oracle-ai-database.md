# Oracle AI Database

The Microsoft/Oracle November announcement describes Oracle AI Database as a
source of governed data, knowledge, and memory for Foundry agents through
approved managed MCP operations. Database@Azure is an Azure deployment offering;
the announcement also describes MCP access to Oracle AI Database in OCI.

Database permissions, application roles, Entra authentication, and auditability
remain distinct from agent orchestration. Workload Center for Oracle is limited
preview; Excel plug-in availability does not verify every customer's entitlement.
