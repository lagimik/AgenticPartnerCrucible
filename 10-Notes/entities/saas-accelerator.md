# SaaS Accelerator

SaaS Accelerator is a reference implementation for connecting SaaS applications
to Microsoft Marketplace subscription and billing workflows. The October 2026
Marketplace article positions it alongside coding-agent instructions, which it
recommends as the starting point for new integrations.

## Operating Boundary

The reference implementation requires adaptation, security and compliance
review, and testing before connection to a live offer. Existing implementations
need version and lifecycle review across all deployed offers and geographies;
current version details belong in the dated resource rather than this definition.
