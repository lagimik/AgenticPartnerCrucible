# Cloud and AI Platform

## What's new?

* 🧩 CAIRA brings composable Azure AI reference architectures for coding agents
* 🚨 Azure SRE Agent patterns turn production incident response into a guarded agent workflow
* 💸 Agent optimization guidance adds four practical levers for lowering cost per outcome


## Deep links

* [CAIRA Composable AI Reference Architectures](https://github.com/microsoft/CAIRA): Microsoft reference library for coding agents that build Azure AI solutions using reusable Terraform, Foundry, Container Apps, TypeScript, C#, and React components that can be copied or adapted per scenario. (GitHub)
* [Azure SRE Agent Incident Response Playbook](https://techcommunity.microsoft.com/blog/microsoftmissioncriticalblog/your-on-call-rotation-has-a-new-member-10-production-incidents-end-to-end-with-a/4545187): Production incident pattern for Azure SRE Agent across App Service, AKS, Azure SQL, Cosmos DB, VMs, Application Gateway, and Service Bus, emphasizing read-only investigation, evidence-backed tickets, human-approved actions, and recovery validation. (Microsoft Mission Critical Blog)
* [Economics of Agent Optimization](https://azure.microsoft.com/en-us/blog/the-economics-of-agent-optimization-four-ways-to-lower-the-cost/): Azure guidance on lowering agent cost through model and offer routing, prompt caching, prompt and agent optimization, observability, and evaluation while preserving quality, safety, and latency. (Azure Blog)
