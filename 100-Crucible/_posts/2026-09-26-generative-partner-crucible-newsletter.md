# Cloud and AI Platform

## What's new?

* 🏭 Useful yield connects AI infrastructure investment to delivered intelligence
* ☸️ Azure container choices converge on one hybrid operating model
* 🧰 Azure KARS turns coding agents into governed multi-runtime workloads
* 🔧 Azure SRE Agent performance depends on routing work to the right handler
* 🧪 Resilience becomes a continuously tested property, not a diagram
* 🏗️ Foundry governance pairs with isolated Container Apps execution

## Deep links

* [The yield imperative: Turning AI infrastructure into useful intelligence](https://blogs.microsoft.com/blog/2026/09/01/the-yield-imperative-turning-ai-infrastructure-into-useful-intelligence/): Microsoft proposes useful yield as capability multiplied by deployment velocity and utilization, helping partners assess output per watt and dollar across power, memory, networking, silicon, models, and agent harnesses. (Microsoft Blog)
* [Microsoft named a Leader in the 2026 Gartner Magic Quadrant for Container Management](https://azure.microsoft.com/en-us/blog/microsoft-named-a-leader-in-the-2026-gartner-magic-quadrant-for-container-management/): Microsoft describes complementary roles for AKS, Azure Container Apps, Azure Arc, and Fleet Manager across persistent AI platforms, elastic agent execution, hybrid estates, and fleet governance; the analyst positioning is Microsoft-reported. (Microsoft Azure Blog)
* [When the Coding Agent Leaves the Codebase: Building a Multi-Runtime AI Agent Infra with Azure KARS](https://techcommunity.microsoft.com/blog/azuredevcommunityblog/when-the-coding-agent-leaves-the-codebase-building-a-multi-runtime-ai-agent-infr/4558449): Azure KARS packages filesystem, shell, long-task, skill, and multiple agent-runtime capabilities as Kubernetes workloads while emphasizing pod-level isolation, trusted tools, credential controls, approvals, and version management. (Microsoft Tech Community)
* [Getting the best out of Azure SRE Agent](https://techcommunity.microsoft.com/blog/appsonazureblog/getting-the-best-out-of-azure-sre-agent/4559745): Production-telemetry-informed guidance prioritizes current data, focused scenarios, response-plan routing, useful skills, specialist agents, scenario-specific autonomy, and permission checks through the final action. (Microsoft Tech Community)
* [Your architecture diagram is not your resilience](https://azure.microsoft.com/en-us/blog/your-architecture-diagram-is-not-your-resilience/): Microsoft recommends proving resilience continuously through application health models, service objectives, estate discovery, failover tests, safe deployment, and evaluation of probabilistic AI dependencies. (Microsoft Azure Blog)
* [Designing agent-first platforms: What changes when agents do the work](https://azure.microsoft.com/en-us/blog/designing-agent-first-platforms-what-changes-when-agents-do-the-work/): The emerging pattern governs identity, grounding, tracing, and evaluation in Microsoft Foundry while executing generated code in isolated Azure Container Apps Sandboxes with scoped access and resumable state. (Microsoft Azure Blog)
