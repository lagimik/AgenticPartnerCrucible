## Deep links

* [Introducing the new Microsoft IQ](https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent/): Package business knowledge, sources, skills, and tools for reuse across Work IQ, Fabric IQ, Foundry IQ, and Web IQ. Start with permission-scoped, measurable processes rather than assuming umbrella GA. Work IQ policy and meeting-context GA wording differs from roadmap estimates; verify exact capability scope, tenant availability, and separately metered API usage. (Microsoft Azure Blog)
* [Microsoft Foundry continuous improvement](https://azure.microsoft.com/en-us/blog/continuous-improvement-comes-to-microsoft-foundry/): Turn traces, expert feedback, and evaluations into reviewed instruction, skill, model, or training improvements. Insights are GA; annotations, golden datasets, skill/cost optimization, and Programmed Training remain preview. Separate configuration changes from model-weight training, and require held-out validation, approved promotion, and rollback rather than assuming automatic production improvement. (Microsoft Azure Blog)
* [Microsoft and Oracle bring enterprise data into the flow of work](https://azure.microsoft.com/en-us/blog/microsoft-and-oracle-bring-agentic-ai-into-flow-of-enterprise-work/): Assess Oracle-backed Excel, Copilot, and Foundry workflows using approved MCP tools, application roles, and audit evidence. Workload Center for Oracle is limited preview; the Excel plug-in announcement does not verify customer prerequisites. Integration is not database migration or unrestricted write authority, and the cited FedRAMP certification is coming soon. (Microsoft Azure Blog)
* [OneLake: The unified foundation for data, context, governance, and AI](https://community.fabric.microsoft.com/blog/fbc_fabricupdatesblogs/onelake-the-unified-foundation-for-data-context-governance-and-ai/5423035): Map lake-first governance, federation, and native Iceberg read/write paths to actual requirements. Catalog is not feature-for-feature Purview Data Governance replacement; Purview protection continues. Sharing and several context features remain preview, while native Iceberg commits differ from virtual metadata over Delta and cannot be made through shortcuts. (Microsoft Fabric Community)
* [Bringing trusted Fabric IQ context to wherever people and agents work](https://community.fabric.microsoft.com/blog/fbc_fabricupdatesblogs/bringing-trusted-fabric-iq-context-to-wherever-people-and-agents-work/5423049): Reuse OneLake data, semantic metrics, and ontologies across supported consumers. Copilot semantic-model access and Fabric IQ MCP are GA; data-agent Copilot GA and ChatGPT/Claude previews are coming soon, Excel is Beta, and ontologies plus selected Foundry knowledge sources remain preview. Verify licenses, permissions, tenant settings, and processing geography per experience. (Microsoft Fabric Community)
* [Build governed data apps with Microsoft Fabric Apps](https://community.fabric.microsoft.com/blog/fbc_fabricupdatesblogs/build-governed-data-apps-with-microsoft-fabric-apps-generally-available/5423011): Pilot GA Fabric Apps and Rayfin with reviewed source grants, entity policies, anonymous settings, and capacity consumption. HorizonDB remains preview. The announcement's independent app-identity wording differs from the connector guide's current item-owner SQL identity; inspect actual runtime access. Semantic models are delegated-only, and lakehouse SQL connectors are read-only. (Microsoft Fabric Community)
* [Semantic chunking and image descriptions in Azure AI Search](https://azure.microsoft.com/en-us/updates?id=563661): Use the GA Content Understanding skill to create grounded Markdown chunks and figure descriptions for Search and Foundry IQ. Search API 2026-10-01 supports these additions; descriptions, embeddings, and image serving require separate configuration. Test permissions, representative documents, separately billed processing, and enrichment errors; the eight-minute analysis polling window is not an end-to-end SLA. (Microsoft Azure Updates)
* [AI-assisted Oracle-to-PostgreSQL application code migration](https://azure.microsoft.com/en-us/updates?id=579231): Evaluate public-preview skills through GitHub Copilot CLI, VS Code, or existing Modernize workflows to identify Oracle dependencies and propose application changes. Developer review and compatibility tests remain required. This is not automatic schema/data migration, complete workload validation, or the separate Oracle-preserving Work IQ integration. (Microsoft Azure Updates)
* [Azure Catalyst expands webapp target coverage](https://techcommunity.microsoft.com/blog/azuremigrationblog/azure-catalyst-expands-webapp-target-coverage/4574689): Compare Container Apps and Managed Instance on App Service with App Service Code/Containers and AKS using dependency discovery, readiness, sizing, and cost assumptions. Optional Copilot code assessment, CAF/WAF design, and approved migration waves remain separate work. Assessment does not perform migration; cost/effort estimates and configuration-specific scale-to-zero are not guarantees. (Microsoft Community Hub)
* [Sovereign Control Panel preview overview](https://learn.microsoft.com/en-us/azure/azure-sovereign-clouds/public/sovereign-control-panel): Build an explicit residency, encryption, network, and continuity assessment scope. The European-region preview stores view data and metadata in Sweden and uses non-enforcing policies. Remediation covers eligible primary-resource residency only; linked copies remain assessment-only. Reports are not real time, and continuity compatibility is neither configured recovery nor certification. (Microsoft Learn)
* [Azure AI Gateway generally available](https://azure.microsoft.com/en-us/updates?id=580080): Govern model and MCP access, routing, usage, and estimated spend through the dedicated managed gateway. Migrate the former APIM AIGateway SKU before January 15, 2027 with reviewed endpoints, identities, roles, and policies. Private endpoints require preview approval; content-safety policy coverage differs from announcement wording. Free gateway requests do not include model consumption. (Microsoft Azure Updates)

# Security

## What's new?

* 🪪 Connect Agent 365 policy to gateway enforcement

* 🔎 Follow third-party signals with Perception

## Deep links

* [Agent 365 integration with APIM and Azure AI Gateway](https://azure.microsoft.com/en-us/updates?id=580055): Join centralized supported-gateway/MCP inventory with runtime server- and tool-level blocking and interaction evidence. The integration is GA, not universal discovery or protection. Validate registration, routed policy enforcement, backend permissions, and applicable Defender/Purview capabilities; inventory and tool access do not authorize consequential business actions. (Microsoft Azure Updates)
* [Agent Grid preview for AI agent communications](https://azure.microsoft.com/en-us/updates?id=580684): Assess identity-based network, destination, and MCP controls outside enrolled ACI/AKS workloads. The update says public preview, but Learn specifies limited-preview access and restricted compute/regions. Attaching compute is not enrollment; private AKS and Foundry hosted agents are unsupported. Workload identities are not Entra Agent ID, and Prompt Shields needs customer-owned Content Safety. (Microsoft Azure Updates)
* [Microsoft Perception expands to third-party data](https://techcommunity.microsoft.com/blog/perception-blog/more-signals-stronger-defense-microsoft-perception-expands-to-third-party-data/4573037): Connect Defender telemetry for cross-system investigation and reviewed detection authoring, with specialized AWS, Okta, and Salesforce expertise. Triage GA covers selected Microsoft-generated Okta/Salesforce alerts, not every agent or source. Verify connector coverage and analyst approval; the reconstructed incident lacked Perception, research simulations are not observed prevention, and investigation timings are not an SLA. (Microsoft Community Hub)
