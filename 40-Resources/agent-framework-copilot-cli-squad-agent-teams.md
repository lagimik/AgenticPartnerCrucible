# Agent Framework, GitHub Copilot CLI, and Squad Agent Teams

Microsoft Agent Framework blog post showing how GitHub Copilot agents can be used through Microsoft Agent Framework, and how Squad can be wrapped as a regular `AIAgent`.

## Summary

The integration lets developers combine Microsoft Agent Framework runtime, model abstraction, hosting, and telemetry with GitHub Copilot CLI/SDK capabilities for repository-aware coding agents. Squad adds multi-agent team orchestration with accumulated project memory, decision logs, reusable skills, and OpenTelemetry spans for dispatched specialists.

## Partner relevance

- Demonstrates a production-oriented pattern for multi-agent software engineering teams.
- Connects GitHub Copilot CLI, MCP servers, and Microsoft Agent Framework into a single developer architecture.
- Useful for partners building agentic development accelerators, code review bots, release-readiness gates, and customer support escalation teams.
