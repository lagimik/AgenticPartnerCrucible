# Azure AI Gateway Labs

Azure Samples repository with more than 30 deployable Jupyter labs for production-oriented AI gateway scenarios.

Labs combine Bicep infrastructure and APIM policies for access control, content safety, private connectivity, backend pooling, token limits, semantic caching, model routing, logging, FinOps, MCP, function calling, and agent frameworks.

The repository also includes Copilot skills for generating labs, APIM policies, Bicep or Terraform, KQL, and MCP servers. It is useful as both a learning path and an implementation reference aligned to Azure Well-Architected pillars.
