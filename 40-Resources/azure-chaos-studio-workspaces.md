# Azure Chaos Studio Workspaces

Azure blog announcement for Chaos Studio Workspaces, a public-preview, scenario-focused approach for validating application resilience through managed chaos engineering.

## Summary

Chaos Studio Workspaces lets teams point a workspace at a subscription or resource group, discover resources, receive recommended scenarios, run controlled resilience drills, and generate scenario reports. Named scenarios include Availability Zone Down, DNS Outage, Microsoft Entra ID Outage, Cache Stampede, Event-Driven Messaging Disruption, and database failover patterns.

## Partner relevance

- Supports Azure Well-Architected reliability assessments and resilience validation offers.
- Creates audit-ready evidence through scenario reports that resemble internal post-incident reviews.
- Extends into AI-powered operations through a GitHub Copilot skill and MCP server for Chaos Studio.
