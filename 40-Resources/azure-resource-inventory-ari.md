## Summary

Azure Resource Inventory (ARI) is a Microsoft-maintained PowerShell module for collecting and documenting Azure environment inventory. Its repository describes report generation and inventory views intended to help teams inspect Azure estates; consult the current README for installation, permissions, supported platforms, and output details.

## Partner Relevance

Use an inventory run as a point-in-time discovery aid for architecture reviews, migration planning, and environment documentation. Confirm that the operator's permissions and the report scope cover the resources under review; an inventory export is not, by itself, proof of compliance or a complete live configuration baseline.
