# CNAPP as a Cloud and AI Security Control Plane

Microsoft summary of the 2026 KuppingerCole Leadership Compass for Cloud Native Application Protection Platforms, which named Microsoft a Leader in its Overall, Product, Innovation, and Market categories.

## Summary

The article describes CNAPP evolving from consolidated cloud-security tooling into a unified control plane for cloud, application, identity, data, runtime, and AI risk. The emphasis shifts from isolated findings and severity scores to correlated, exploitable attack paths across multicloud and hybrid environments.

Microsoft Defender for Cloud is positioned around three connected capabilities:

1. Correlate posture, identity, data, network, workload, application, and AI signals through security graphs and attack-path analysis.
2. Treat AI models, agents, pipelines, and machine identities as part of cloud risk while using security agents to investigate and guide remediation.
3. Connect code-to-cloud controls, runtime protection, cloud detection and response, and SOC workflows.

## Partner relevance

- Supports a unified cloud-and-AI security assessment rather than separate posture projects.
- Prioritizes remediation using exploitability and runtime context.
- Extends CNAPP conversations to AI security posture management and agentic security operations.
- Connects developer security, cloud operations, and SOC transformation services.

The market-position claims originate from a Microsoft-authored summary of the analyst report; customers should review the report context and their own requirements.
