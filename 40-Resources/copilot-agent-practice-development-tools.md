# Copilot and Agent Practice Development Tools

Microsoft's FY27 practice-development motion turns Copilot and agent expertise into a repeatable partner business through four stages: strategy, capability development, offer development, and go-to-market.

## Tool-Backed Practice Motion

| Stage | Tool | Outcome |
| --- | --- | --- |
| Design strategy | [Automated Readiness Assessment](https://aka.ms/MARA) | Establish an evidence-led customer readiness baseline |
| Design strategy | [ME7 and Agent 365 webinar series](https://aka.ms/ME7A365WebinarSeries) | Frame productivity, security, compliance, AI, and agent management as one platform |
| Develop capabilities | [M365 Copilot MSP Playbook](https://aka.ms/M365CopilotMSPPlaybook) | Define a managed-service lifecycle from readiness through support and reporting |
| Build offers | [Marketplace Offer Assessment](https://aka.ms/OfferValidator) | Test value proposition, outcomes, KPIs, packaging, and call to action |
| Build offers | [Agent Build-Along Series](https://aka.ms/agent-build-along) | Convert repeatable build patterns into assessment, pilot, and automation offers |
| Go to market | [Pitch-Maker Agent](https://aka.ms/ThePitchMakerAgent) | Turn usage and opportunity signals into executive value stories |

## Durable Pattern

Differentiate with a chain of proof: assess readiness, establish a secure platform point of view, build repeatable delivery routines, package outcome-led offers, and sell with customer-specific evidence.
