# Copilot Analytics Labs

## Source Summary

[Copilot Analytics Labs](https://microsoft.github.io/CopilotAnalyticsLabs/)
describes itself as a DIY hub for **experimental** Copilot and agent analytics,
with templates, sample code, research, and adoption guidance.
The public [catalog source](https://github.com/microsoft/CopilotAnalyticsLabs/blob/main/src/data.ts)
includes ValueLens for value and cost analysis, Consumption Central for
cross-product credit consumption, AI in One Dashboard, and organization-level
GitHub Copilot analytics.

These are catalog descriptions, not independent validation of each report.
The repository README is a generic React/Vite template; use the selected
tool's own repository for data sources, deployment steps, permissions, and
license prerequisites.

## Partner Application

**Interpretation:** Choose one measurement question, validate a template with
sample data, review collection and privacy requirements, and establish a
customer-specific baseline before using tenant data. Keep usage, estimated
hours saved, modeled ROI, and demonstrated business outcomes separate.

This hub is distinct from [Analytics Hub](analytics-hub.md), although their
catalogs overlap. Link to the owning tool rather than maintaining duplicate
setup instructions. No reports, scripts, or data collectors were executed.
