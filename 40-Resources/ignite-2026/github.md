## GitHub

### Copilot SDK 2.0

Microsoft announces SDK 2.0 GA with a Rust-based Copilot harness and support
across six languages. The announcement frames it for agent embedding and
multi-tenant, high-scale deployments.
**Partner interpretation:** validate tenant isolation, identity propagation,
tool permissions, failure recovery, observability and actual usage charges.
A production-proven harness does not make a customer's application safe by
default. [Source follow-up](https://aka.ms/copilot-sdk/blog-2.0).

## Introductory Mentions

The GitHub overview also discusses Azure DevOps repository workflows in the
Copilot app, logged-in browser testing, local code review, secret detection,
adaptive review effort, cross-repository context and repository insights.
These are not separate announcement entries and lack individual release
labels in this source; SDK GA must not be inherited by all of them.
