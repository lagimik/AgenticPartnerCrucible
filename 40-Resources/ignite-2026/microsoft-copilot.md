# Ignite 2026 - Microsoft Copilot

Ten paraphrased announcement entries follow the source's Microsoft Copilot
category. Release labels are from the
[Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/),
not a tenant entitlement or rollout test.

## Microsoft Copilot

### Agent 365 FinOps and business analytics

Cost controls are preview; forecasting and business analytics have Frontier
availability. Additional value insights/delegation are planned for December.
The source distinguishes a tenant Copilot license requirement for Microsoft
service insights from Agent 365 licensing for non-Microsoft insights.
Cost visibility, spending controls and measured business value are different
capabilities.
[Source follow-up](https://techcommunity.microsoft.com/blog/ai-finops-blog/introducing-microsoft-agent-365-business-analytics-turn-ai-investment-into-busin/4574149).

### Autopilot

The long-running personal agent is rolling out through Frontier. It has a
tenant-resident agent identity, memory and tool access; colleagues can interact
with supported scenarios. Persistent work still needs authorized actions,
owner/admin control and bounded spending.
[Source follow-up](https://aka.ms/MicrosoftIgnite26Blog).

### Copilot Managed Runtime

Managed Runtime is announced GA, with optional Fabric data/backend services
separate from application hosting. The source also describes locally developed
Studio agents/workflows and CLI publication without individually assigning all
new paths a release label.
[Source follow-up](https://aka.ms/CopilotManagedRuntime-Ignite-Blog).

### Copilot Workspaces

Workspaces evolves Notebooks into shared workstream context and collaboration.
It is Frontier; bringing personal Autopilot into Workspaces is described as
coming soon. Shared context requires appropriate membership and permissions.
[Source follow-up](https://aka.ms/MicrosoftIgnite26Blog).

### Dynamics 365 CRM and ERP plugins

Sales and ERP plugins are announced GA for permissioned sales, finance and
operations tasks in Copilot/Cowork/Excel. The source's follow-up points to an
Agent 365 analytics alias; topical fit was not verified. The Book of News,
not that unexplored alias, is the evidence for this summary.
Existing business permissions and action approvals remain necessary.

### Copilot Code

Code is Frontier across named platforms; GA is announced for December, not
the capture date. Local sandbox support is Windows-first, with macOS planned.
Tenant sandboxing and publishing controls are boundaries to validate, not a
guarantee that generated applications are production-ready.
[Source follow-up](https://aka.ms/MicrosoftIgnite26Blog).

### Home, Auto and Office

Home is rolling out worldwide. Chat-to-Cowork routing and Office in Copilot
are GA; Decision-1.1 effort selection is Frontier, and Cowork declarative-agent
invocation is private preview. Files retain OneDrive permissions and
Microsoft 365 controls. Do not collapse these statuses into one product label.
[Source follow-up](https://aka.ms/MicrosoftIgnite26Blog).

### Dynamics 365 Activate

Salesforce-to-CRM migration is GA. SAP ECC discovery and ERP implementation
capabilities have staged rollout language rather than a blanket GA assertion.
Project teams review recommendations, dependencies, configuration and data
migration against Success by Design.
[Source follow-up](https://aka.ms/D365Ignite2026).

### Salesforce integrations

Salesforce in Copilot is preview, Sales Cloud in Teams is pilot and supported
Fabric OneLake data federation into Data 360 is GA. Zero Copy describes an
access/data-placement model, not universal bidirectional write support.
Authenticated Salesforce MCP and source permissions still constrain actions.
[Source follow-up](https://aka.ms/AA1457n5).

### Today

Today is a planned private Frontier preview. Brief is described as a daily
Copilot-license capability; recurring Feed updates require credits.
Prepared messages and scheduling changes are for user review/approval, not
automatic authorization to send or reschedule.
[Source follow-up](https://aka.ms/MicrosoftIgnite26Blog).
