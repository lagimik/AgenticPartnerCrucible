# Ignite 2026 - Microsoft Edge

## Edge for Business

### Governed agent browsing and browser security

The [Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/)
announces extension safety GA. Skills recorder with Cowork, agent-specific
managed browser windows, extension leak control, the Sentinel connector and
Entra Global Secure Access integration are preview.

Recorded workflows reuse a user's existing permissions; they do not gain
authority from being a skill. Agent identity/window separation, inventory,
page data-access restrictions and network policy are distinct controls.
**Partner interpretation:** test credentials, protected pages, agent/human
activity attribution and supported browser enforcement before expanding
automation. [Source follow-up](https://aka.ms/EdgeIgnite26).

The source's browser market-position statement is scoped to Windows browser
minutes at organizations with more than 1,000 employees. It is not a universal
market-share claim. Visual-asset collections were not ingested.
