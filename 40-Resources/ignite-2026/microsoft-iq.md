# Ignite 2026 - Microsoft IQ

Seven category/announcement pairs follow the
[Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/).
The platform combines context management and continuous improvement.
Its GA/no-new-SKU framing does not imply that all integrations are GA, included
in every license, enabled or free.

## Microsoft IQ

### Enterprise AI platform

Microsoft IQ is announced GA on existing products, with no new SKU or
subscription for the platform framing. Context and reusable expertise feed
applications/agents, while Foundry evaluations and optimization feed learning.
Agent 365 is a separate governance connection, not implicit authorization.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Microsoft IQ: Enterprise context management

### Reusable business expertise

The source describes GA context access and reusable plugins, skills, tools and
agents, with scenario-specific business plugins separately in Frontier.
Business plugins can inherit organization/business-unit/project guidance
with labels and change auditing. Interpretation: governed guidance helps route
context and expertise, but does not replace deterministic tool authorization.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Foundry IQ

### Unstructured enterprise knowledge

Knowledge graphs, Microsoft-Retriever-1 and automatic project grounding
resources are preview. SharePoint indexed knowledge is GA with source
permissions. Retrieval planning, entity relationships and citations need
evaluation against actual source completeness and user access.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Fabric IQ

### Trusted data, metrics and operational meaning

The item combines OneLake data, Power BI measures, ontologies and data agents.
Copilot access to Power BI semantic models and named Fabric-app integrations
are GA. Excel's Edit with Copilot/Fabric-connected PivotTables, GitHub ontology
integration and ChatGPT/Claude connectors are explicitly preview in the
detailed text. Keep consuming-channel behavior, identity and permissions
separate from the underlying semantic model.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Web IQ

### Governed external knowledge

Web IQ, Auto, Auto Advanced, Scopes, Places, Weather and health-aware ranking
are announced GA. Commerce is private preview. Include/exclude scopes restrict
source selection; cited web content still needs credibility, freshness and
task-fit review. Health ranking does not independently validate clinical advice.
[Source follow-up](https://aka.ms/webiqnews).

## Work IQ

### Work context, actions and enterprise controls

Expanded context/retrieval and supported actions are described as GA; listen
events and expanded governance/approval controls are preview.
The partner-platform bullet also says OpenAI/Anthropic integrations are
coming soon, so those particular integrations remain planned in these notes.
Permission-aware retrieval is not unlimited access or approval for a write.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Continuous improvement

### Carrying validated learning into future work

The source connects production signals, outcome criteria, optimization and
model post-training. Approved configuration, reusable skills and evaluations
carry forward into future agents. The
[Foundry page](microsoft-foundry.md#continuous-improvement-in-foundry) owns
the detailed evaluation/training announcements.
[Source follow-up](https://aka.ms/miq-ignitelaunchblog).

## Release-status reconciliation

The Fabric IQ introduction broadly calls integrations GA, while named detailed
bullets call several preview. Work IQ combines broad GA wording with planned
OpenAI/Anthropic support. The later improvement overview does not override the
Foundry item's explicit Managed Training preview. Prefer specific capability
labels and retain these source tensions until implementation documentation
establishes exact scope.
