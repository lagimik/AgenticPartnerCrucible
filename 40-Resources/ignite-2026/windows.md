# Ignite 2026 - Windows

Six announcement summaries preserve the source's Windows category.
Availability labels are attributed to the
[Book of News](https://news.microsoft.com/events/ignite/2026/book-of-news/).
Local, Cloud PC and server execution have different operational and licensing
boundaries; placement alone does not establish security or residency.

## Windows

### Copilot file operations, diagnostics and search

The on-device file-management, diagnostic and taskbar Search additions are
preview. File access, write operations, diagnostic collection and IT-managed
experience controls need separate authorization and validation.
[Source follow-up](https://aka.ms/WindowsAtIgnite2026).

### Windows 365 connectivity and administration

Direct Stream connectivity improvements and context-based redirection are GA.
GPU streaming additions are planned preview early next year in selected regions.
The admin assistant and Windows MAM are preview. Conditional redirection
depends on the connection's authentication/trust context.
[Source follow-up](https://aka.ms/W365Ignite26Blog).

### Windows and Intune platform controls

Windows Endpoint Security Platform is announced GA. Baseline protection,
server/client-like management, broader application auto-updates, experience
controls and reliability reporting have private previews; declarative device
management is preview. Verify each control's actual enablement and support.
[Source follow-up](https://aka.ms/WindowsAtIgnite2026).

### Windows 365 for Agents

The source describes eligibility for Copilot Credits and Standard-harness
computer use. Microsoft Copilot harness support is planned preview in December;
Foundry MCP integration is planned preview early next year.
On-premises application access with agent identities and persistent Cloud PCs
are preview, with Frontier qualification for persistence.
[Source follow-up](https://aka.ms/W365Ignite26Blog).

### Local and hybrid AI placement

Appropriately sized Windows 365 Cloud PCs can run supported local models as GA.
Windows Server 2025 with AVD Hybrid is private preview. Compare compatible model
runtime, compute capacity, data access and operating responsibility instead of
assuming every workload can move between these placements.
[Source follow-up](https://aka.ms/WindowsAtIgnite2026).

### Windows process-container governance

New COM/IPC, network and identity-proofing controls are preview.
Learning/permissive mode is explicitly GA despite the item's broad preview
introduction. Observe normal behavior before enforcing policy, but do not
treat permissive observation as enforced isolation.
[Source follow-up](https://aka.ms/WindowsAtIgnite2026).
