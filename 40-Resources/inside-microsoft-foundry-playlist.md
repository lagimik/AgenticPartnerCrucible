# Inside Microsoft Foundry Playlist

Microsoft video series for developers, architects, data scientists, and enterprise IT teams building and operating AI applications and agents with Microsoft Foundry.

The series combines platform overviews, demonstrations, and production guidance across model selection, agent development, tool and data connections, evaluation, deployment, monitoring, security, governance, and scaling from proof of concept.
