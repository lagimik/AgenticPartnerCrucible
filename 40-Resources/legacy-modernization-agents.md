# Legacy Modernization Agents

Microsoft sample accelerator for understanding COBOL estates before generating Java/Quarkus or C#/.NET modernization output.

## Delivery Pattern

1. Inventory programs, copybooks, JCL chains, data access, and unresolved dependencies.
2. Extract business purpose, rules, use cases, and glossary terms for validation with subject-matter experts.
3. Classify parse fidelity and modernization readiness before selecting automation candidates.
4. Map dependencies and centrality to define migration waves and missing-source remediation.
5. Convert toward the customer's chosen Java or .NET target architecture.
6. Apply deterministic structural parity checks, then add compilation, characterization, regression, reconciliation, performance, and security testing.

## Important Boundary

The sample's structural parity validation does not prove behavioral correctness. Treat generated code as an accelerator within a governed modernization method, not as production-ready output by default.
