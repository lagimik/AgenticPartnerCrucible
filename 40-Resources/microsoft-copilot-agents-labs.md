# Microsoft Copilot Agents Labs

## Source Summary

The [public Microsoft lab hub](https://microsoft.github.io/mcs-labs/) offers
events, workshops and guided modules for Copilot and Copilot Studio agents.
Its latest [Copilot & Agents Bootcamp](https://microsoft.github.io/mcs-labs/events/architecture-bootcamp/),
updated November 9, lists three days, 17 modules and 11 labs.

The agenda progresses from Copilot Chat/Work IQ and Cowork to harnesses,
instructions/skills, knowledge/tools/hooks, apps, workflows and agent
integration, then ALM, evaluations, coding agents, FinOps and identity.
Archived event pages also exist; select the current event, not merely a familiar URL.

## Partner Interpretation

Build an enablement path around a scoped agent and checkable grounding, tool
authorization, handoff, lifecycle and consumption evidence. Use individual
modules for targeted practice gaps rather than assuming the full agenda is
required for every engagement.

The reviewed [Standard lab introduction](https://microsoft.github.io/mcs-labs/labs/standard-harness-components/)
distinguishes Standard from the renamed Microsoft Copilot harness. It calls for
provisioned training accounts or own-tenant prerequisites, fictitious data and
no tenant-setting changes; model availability can vary by tenant.

## Evidence Boundaries

The hub, agenda and one lab's introduction/setup were reviewed. Labs were not
executed and linked slides were not downloaded or reviewed. Verify each module's
license, tenant, feature and model requirements before scheduling a workshop;
public learning material does not establish free product usage or universal access.
