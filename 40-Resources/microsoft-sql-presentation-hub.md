# Microsoft SQL Presentation Hub

## Source Summary

The [public hub](https://mssqldecks.azurewebsites.net/) describes its Microsoft SQL
presentations, demos and deep dives as public-facing and available for reuse.
The page provides title/topic/presenter search and event/collection navigation.

Reviewed initial records in the [public catalogue](https://mssqldecks.azurewebsites.net/decks.json)
include the SQLCon/FabCon EU 2026 roadmap corenote, AI-assisted SQL performance
troubleshooting, SQL SDLC/live sites, Hyperscale and Data Productivity Tour.
These are catalogue descriptions, not verified slide content or feature claims.

## Partner Interpretation

Use the hub to discover material for SQL modernization, database performance or
developer enablement. Check the chosen asset's update date, audience, product
scope and feature status before presenting it to customers. Keep roadmap
discussion distinct from delivered capabilities.

## Evidence Boundaries

The simplified page initially exposed only a hidden no-results placeholder.
Full public HTML and the initial catalogue records established the hub's purpose;
the placeholder is not evidence of an empty catalogue.

No presentation downloaded, content reviewed or download access tested.
The publisher's public reuse statement does not independently establish rights
for all embedded third-party material. Public curation is a hub pointer only.
