## Summary

Microsoft What The Hack is a public, MIT-licensed collection of facilitated,
challenge-based technical hackathons. Squads solve progressively scoped goals
without step-by-step instructions while coaches provide guidance, demos, and
solution reviews without giving participants the answers.

## Partner Use

* Run applied skilling events for groups of five to 50 people
* Convert product training into collaborative, scenario-based practice
* Assess whether participants can combine documentation, judgment, and
  implementation skills
* Adapt existing hacks or use the authoring templates to create customer- or
  industry-specific challenges

## Coverage

The collection spans Azure AI, infrastructure, application development,
operations, data and AI, Microsoft Teams, edge and devices, networking, SAP on
Azure, and Power Platform. AI and developer options include Azure OpenAI
fundamentals, Azure OpenAI application development, Build Your Own Copilot,
GitHub Copilot, Microsoft Fabric, MLOps, GitHub DevOps, and agent observability.

## Delivery Considerations

* Use the hosting guide to prepare coaches, participants, timing, and
  environments
* Keep coach material private until the event is complete
* Validate prerequisites, deployment scripts, service availability, and costs
  before selecting a hack
* Check the archived section and recent repository activity because individual
  hacks can become obsolete as services change
* Treat the catalog as facilitated experiential learning rather than
  certification preparation or a step-by-step lab library
