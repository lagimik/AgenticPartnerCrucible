# Security Advisors Program Member Sign-up

Source: Microsoft Forms sign-up page for Security Advisors Program membership.

Raw capture: `raw/2026-08-01-security-advisors-program-member-sign-up/`

## Summary

The Security Advisors Program is a voluntary Microsoft Security community/advisory program for experienced security community participants who want engagement opportunities with participating Microsoft product engineering teams. The form positions membership around private previews, product roadmap/update discussions, feedback to engineering, customer-to-customer learning, and confidentiality obligations.

## Participating Security Advisors programs

- Management Advisors Program: Microsoft Intune, Windows Cloud, and Windows Commercial.
- Microsoft Entra Advisors Program: Microsoft Entra ID, ID Protection, ID Governance, External ID, Verified ID, Workload ID, Internet Access, and Private Access.
- Microsoft Purview Advisors Program: Information Protection, Data Loss Prevention, Insider Risk Management, Data Governance, eDiscovery, Audit, Data Lifecycle Management, Records Management, and Microsoft Priva.
- Microsoft Threat Protection Advisors Program: Microsoft Sentinel, Microsoft Defender products, and Azure network security services.

## Membership requirements

- Experienced in managing Security Customer Community products.
- Committed to using Security Customer Communities private previews and providing feedback.
- Enthusiastic about community engagement.
- Dedicated to maintaining confidentiality.

## Member benefits

Benefits vary by participating Security Advisors Program and may include virtual meetings on product updates and roadmaps, interaction with engineering team members, customer-to-customer learning, opportunities to provide feedback, and learning about Microsoft products and services including private previews.

## Confidentiality and opt-in notes

The program states that private previews, program materials, product roadmaps, Teams community call discussions, and surveys are Microsoft Confidential Information. Members who opt in may be added to selected Security Advisors Program Microsoft Teams groups, where Microsoft employees and other members can see their name and contact details. Teams calls and events may be recorded and shared with other Microsoft community programs.

The form also includes a separate opt-in for member recognition benefits, including digital badges and reward points for meaningful contributions and feedback. That benefit may involve sharing first name, last name, and email address with Credly.

## Form profile areas

The sign-up collects contact and profile information, MVP status, organization details, relationship to Microsoft, Microsoft contacts, target Security Advisors Programs, non-Microsoft platforms in the current environment, and experience across Defender/XDR, Defender for Cloud, network security, Purview and Priva, Intune/Windows, Entra, development platforms, and AI tools.
