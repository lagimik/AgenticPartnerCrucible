# Useful Yield for AI Infrastructure

Microsoft proposes "useful yield" as the output-oriented measure for AI
infrastructure: useful intelligence produced from capital, power, memory,
networking, silicon, models, and agent harnesses.

## Core Model

The article expresses useful yield as:

`Capability x Deployment Velocity x Utilization`

Losses and gains compound across the stack. More capacity alone does not ensure
more useful output, particularly as long-running agent workflows consume far
more tokens and retain more context than chat interactions.

## System Constraints

- Memory efficiency depends on model architecture, compression, software,
  compilers, data movement, and silicon working together.
- Network productivity includes congestion control, recovery, placement, and
  programming complexity, not only link speed.
- Power and cooling must be designed from grid to chip, with hardware-software
  controls that protect critical workload performance.
- Cross-layer co-design can turn apparent component limits into solvable system
  constraints.

## Partner Relevance

Partners can use useful yield to structure AI infrastructure assessments around
business output per watt and dollar, utilization, deployment velocity, model
routing, and whole-stack bottlenecks rather than raw capacity acquisition.
