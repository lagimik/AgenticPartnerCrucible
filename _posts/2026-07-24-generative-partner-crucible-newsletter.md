# Microsoft 365 Copilot Workloads

## What's new?

* 🧩 Agent 365 PoC guidance gives partners a repeatable customer conversation model
* 🧠 CAT Agent Skills adds a Business OS pattern for more consistent Copilot Studio agents
* 🛠️ Modern Copilot Studio updates focus on plugins, multi-agent patterns, MCP, runtime skills, and partner practice building

## Deep links

* [Agent 365 Demo-Led PoC Kit](https://aka.ms/Agent365PoC/Download): Partner-facing proof-of-concept kit for helping customers gain visibility into their agent estate, address governance challenges, and develop an AI agent strategy. (Microsoft)
* [CAT Agent Skills](https://microsoft.github.io/cat-agent-skills/): Business OS for Copilot Studio gives agents structured approaches for clarifying outcomes, solving problems, making decisions, planning projects, improving processes, handling incidents, and creating reusable skills. (Microsoft GitHub Pages)
* [Copilot Studio Plugin](https://github.com/microsoft/copilot-studio-plugin): Experimental PAC CLI plugin for creating, editing, validating, and migrating classic agents to the new Copilot Studio experience. (GitHub)
* [New Copilot Studio Tech Guide](https://microsoft.github.io/new-copilot-studio-tech-guide/): CAT team technical guide for the rebuilt Copilot Studio experience, covering connected agents, MCP servers, runtime skills, generated files, workflows, and the BlastBox Omega reference scenario. (Microsoft GitHub Pages)
* [Modern Copilot Studio - Technical Deep Dive](https://www.linkedin.com/posts/harish-purohit_modern-copilot-studio-ugcPost-7482829813083467776-U2yC/): Technical deep dive into the modern Copilot Studio experience and its architectural changes. (LinkedIn)
* [Agentic Apps PP and CS Partner Practice Guide](https://microsoftpartners.microsoft.com/Downloads/?filename=/abs/protected/Agentic-Apps-PP-and-CS-Partner-practice-guide.pptx): Partner practice guide for building an agentic apps practice with Power Platform and Copilot Studio. (Microsoft Partners)
