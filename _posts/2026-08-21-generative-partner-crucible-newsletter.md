# Cloud and AI Platform

## What's new?

* ⚡ Hypervelocity Engineering with  GitHub Copilot

## Deep links

* [Hypervelocity Engineering Core](https://github.com/microsoft/hve-core): Microsoft agentic software-development framework for GitHub Copilot that packages specialized agents, reusable prompts, coding instructions, skills, and a Research-Plan-Implement-Review operating model into repeatable engineering workflows. (GitHub)
* [Choosing the Right Agent in Microsoft Foundry](https://techcommunity.microsoft.com/blog/azurearchitectureblog/choosing-the-right-agent-in-microsoft-foundry/4547827): Architecture guide that distinguishes Foundry prompt agents from hosted agents by ownership of orchestration, state, custom code, middleware, multi-agent coordination, and operational complexity. (Azure Architecture Blog)
* [AI Agents for IT and Operations Workshop](https://github.com/microsoft/AIAgentsforITOps): Microsoft workshop for infrastructure management of AI agents, covering managed identity and RBAC, private networking, Key Vault, observability, cost management, and comparative custom AKS-hosted versus Foundry-hosted agent paths. (GitHub)
* [Giving AI Spend a Name in FOCUS](https://techcommunity.microsoft.com/blog/finopsblog/who-ordered-all-these-tokens-giving-ai-spend-a-name-in-focus/4547978): FinOps guidance applying the FinOps Open Cost and Usage Specification to AI costs through enrichment dimensions such as model or agent name, token type, product line, use case, unit of measure, and provider. (FinOps Blog)
* [Microsoft Cloud-Native Application Platform Leader 2026](https://azure.microsoft.com/en-us/blog/microsoft-named-a-leader-in-the-2026-gartner-magic-quadrant-for-cloud-native-application-platforms/): Microsoft announcement positioning Azure App Service, Container Apps, Functions, API Management, Foundry, GitHub Copilot, Azure Monitor, Application Insights, and Azure SRE Agent as an integrated foundation for modernization and AI delivery. (Azure Blog)
* [Browser Automation with Pydantic AI and Playwright](https://techcommunity.microsoft.com/blog/azuredevcommunityblog/browser-automation-with-pydantic-ai--playwright/4547971): Implementation pattern combining Pydantic AI, Playwright browser control, Microsoft Foundry models, Microsoft Entra authentication, domain restrictions, private-network blocking, traceability, and human control for sensitive workflows. (Azure Developer Community Blog)
