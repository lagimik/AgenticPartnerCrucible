## Direct Source Summary

What The Hack is a collection of challenge-based technical hackathons that can
be delivered in person or virtually through Microsoft Teams. Participants work
in squads of three to five people. Each challenge defines high-level goals
rather than step-by-step instructions, requiring participants to collaborate,
research, and develop a solution.

Coaches guide squads without supplying answers. They can introduce challenges
with lectures or demonstrations and review solutions as the event progresses.
The hosting format supports groups of five to 50 people.

The repository contains coach material for organizations hosting events. It
also provides hosting and authoring guides, contribution instructions, and
templates for creating new hacks. The README directs students to the What The
Hack website and asks hosts to share coach content only after an event.

The catalog spans Azure AI, infrastructure, application development,
operations, data and AI, Microsoft Teams, edge and devices, networking, SAP on
Azure, and Power Platform. Current AI-oriented entries include Azure OpenAI
Fundamentals, Building AI Apps with Azure OpenAI and the Azure Ecosystem, Build
Your Own Copilot, GitHub Copilot, Fabric Real-Time Intelligence, and Data
Science in Microsoft Fabric.

## Interpretation

What The Hack is best treated as a facilitated experiential-learning format,
not a self-paced tutorial library. Partners can use the catalog to run customer
or team enablement events, assess applied capability, and adapt scenario-based
technical content under the MIT license. Hosts should validate each hack's
dependencies and currency before scheduling an event because the collection is
community maintained and includes an explicit archive for obsolete material.
