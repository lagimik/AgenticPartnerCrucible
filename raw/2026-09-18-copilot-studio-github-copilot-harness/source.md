## Direct Source Summary

The GitHub Copilot harness is a natural-language-first Copilot Studio authoring and runtime option alongside the standard and Copilot Chat harnesses. Builders configure instructions, knowledge, tools, reusable skills, models, memory, and connected agents, then use Build, Preview, Evaluate, and Monitor activities before publication.

Harness selection affects orchestration, capabilities, publishing, billing, and portability. Microsoft states that agents cannot be transferred between the GitHub Copilot and standard harnesses. The natural-language automation builder can propose deterministic workflows, conversational agents, or a combination, but the documented experience is a production-ready preview and can require explicit connections, permissions, and external-model policy decisions.

Agent Academy provides hands-on GitHub Copilot harness training. The separate GH-300 certification covers responsible use, prompt and context practices, GitHub Copilot architecture, productivity, privacy, content exclusions, and safeguards.

## Evidence Notes

- Harness selection is an early architecture decision, not a designer preference.
- Building, testing, evaluating, and using agents can consume Copilot Credits.
- Natural-language generation does not remove connection, permission, evaluation, governance, or monitoring requirements.
- Preview features, model availability, licensing, and billing details can change.

## Interpretation

Partners can package harness-selection assessments, solution blueprints, evaluation and observability services, Copilot Credit sizing, governed agent factories, and combined Agent Academy plus GH-300 enablement.
