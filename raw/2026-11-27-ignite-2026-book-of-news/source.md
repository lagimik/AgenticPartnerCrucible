## Paraphrased Source Summary

### Azure

The source distinguishes GA infrastructure and database capabilities from
preview deployment, isolation, confidentiality, agent operations and migration
features. Its Data category includes Fabric and Power BI announcements: retain
that placement for event navigation, while connecting existing Fabric notes.
Azure HorizonDB is announced GA; Fabric HorizonDB is separately preview.

### Microsoft Foundry

The source describes evaluation, production insights, optimization and training
as an improvement loop, followed by decision models and a broader model
portfolio. Model, API, hosting platform and training statuses differ.

### GitHub

The numbered announcement concerns Copilot SDK 2.0 and its Rust-based harness,
announced GA across six languages. Introductory app/browser/code-review mentions
do not individually establish GA for all named features.

### Microsoft Copilot

The source separates the Home/Office experience, Code, Autopilot, Workspaces,
Managed Runtime, business plugins, migration and Salesforce integration.
GA, Frontier, private preview, pilot and future rollout dates coexist.

### Microsoft Edge

The browser category combines agent workflow recording and managed browsing
with extension risk, data leakage, Sentinel and identity-aware network access.
Extension safety is GA; the other named additions have preview qualifications.

### Microsoft IQ

The platform groups context management and continuous improvement. Work IQ,
Fabric IQ, Foundry IQ and Web IQ provide distinct context surfaces; reusable
plugins, skills, tools and agents are not interchangeable. Platform GA and
no-new-SKU language do not make all integrations GA or usage free.

### Security

The source organizes security by Agent 365, MDASH, Defender, Entra, Intune,
Perception and Purview. Perception's core GA announcement does not extend to
every new playbook, testing agent or agent-risk capability. Licensing and
approval boundaries remain material.

### Windows

The source covers Copilot on-device assistance, Windows 365, endpoint management,
agent Cloud PCs, local/hybrid model placement and process-container controls.
Available capabilities coexist with Frontier, private previews and future
December/early-next-year plans.

## Evidence Tensions to Preserve

- Agent Optimizer is described as GA here; the insights-driven workflow's Learn
  page reviewed on 2026-11-27 still labels that workflow preview. Scope/version
  equivalence is unconfirmed.
- The Fabric IQ introduction broadly describes integrations as GA, but its
  detailed bullets label Excel editing, GitHub ontology integration and
  ChatGPT/Claude connectors preview. Keep the specific capability labels.
- Work IQ's partner-platform bullet combines general availability language with
  OpenAI/Anthropic integrations described as coming soon. Planned integrations
  must not be represented as delivered.
- Managed Training is explicitly preview in the Foundry item; the later IQ
  overview's broader GA framing does not establish a different status.
- Windows process-container additions are broadly preview, but learning and
  permissive mode is explicitly GA.
- The Cosmos DB item says seven updates but visibly enumerates six named
  capabilities. Do not invent a seventh.
- The Dynamics 365 plugins item's follow-up link points to
  `https://aka.ms/A365AnalyticsLearn`; its topical fit was not established.

These are source interpretation and verification limits, not proof that a
publisher assertion is false. The derived notes cite the original source and
separate announcements from partner interpretation.
